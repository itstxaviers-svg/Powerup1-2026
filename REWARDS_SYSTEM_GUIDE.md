# WORD//CODE — система наград

Этот файл описывает систему наград в понятной форме и фиксирует правила, которые уже реализованы в приложении.

## 1. Главная идея

Награды поддерживают обучение, но не заменяют его. Основной игровой цикл:

**Выполняй задания → получай Energy → восстанавливай Crystal Cores → открывай миры → развивай Code Spirit → находи артефакты.**

Система состоит из четырёх связанных частей:

1. **Code Spirit** — личный персонаж ученика.
2. **Crystal Cores** — прогресс по учебным юнитам.
3. **Secret World** — карта территорий, которые открываются вместе с юнитами.
4. **Artifact Collection** — коллекция за разные виды учебной активности.

Ошибки не отнимают Energy, уровни, кристаллы или учебный прогресс.

## 2. Energy и уровни

Energy начисляется за каждое выполненное задание:

| Результат | Energy |
|---|---:|
| Правильный самостоятельный ответ | +14 |
| Правильный ответ после подсказки | +9 |
| Ошибка или попытка, требующая повторения | +3 |
| Полное восстановление Stability до 100% | +20 |

Даже ошибочная попытка даёт небольшое количество Energy, потому что ученик всё равно занимался и взаимодействовал с материалом.

Каждые **1000 Energy** повышают уровень:

- 0–999 Energy — Level 1;
- 1000–1999 Energy — Level 2;
- 2000–2999 Energy — Level 3;
- и так далее.

Общее количество заработанной Energy и достигнутый уровень никогда не уменьшаются из-за отсутствия активности.

## 3. Развитие Code Spirit

Внешний вид персонажа зависит от уровня:

| Стадия | Открывается |
|---|---:|
| Spark | Level 1 |
| Sprite | Level 2 |
| Spirit | Level 3 |
| Guardian | Level 4 |
| Master Spirit | Level 7 |

Дополнительно открываются визуальные аксессуары:

| Аксессуар | Открывается |
|---|---:|
| Crystal Core | Level 1 |
| Neon Wings | Level 2 |
| Star Aura | Level 3 |
| Decoder Halo | Level 5 |
| Prism Trail | Level 7 |

Открытая стадия и аксессуары остаются у ученика навсегда.

## 4. Crystal Cores

У каждого юнита есть собственный кристалл. Он восстанавливается по частям юнита.

Например, юнит с четырьмя группами показывает:

- одна завершённая группа — 25%;
- две группы — 50%;
- три группы — 75%;
- четыре группы — 100%.

Если в юните две группы, каждая даёт 50%. Если три — примерно 33%.

В текущей реализации группа считается пройденной, когда ученик попробовал все учебные цели этой группы. Это состояние **Restored**. Более высокий статус **Mastered** появляется только тогда, когда все цели юнита достигли учебного состояния `mastered`.

Таким образом:

- **Restored** означает, что весь материал юнита пройден;
- **Mastered** означает, что материал устойчиво освоен в нескольких режимах и не за одну короткую попытку.

Полученный Crystal Core не отнимается.

## 5. Secret World

Полностью восстановленный Crystal Core открывает территорию:

| Учебный блок | Территория |
|---|---|
| Hello! | Gateway |
| Unit 1 | Crystal Academy |
| Unit 2 | Mirror Garden |
| Unit 3 | Sky Farm |
| Unit 4 | Floating Café |
| Unit 5 | Starlight Library |
| Unit 6 | Sun Pyramid Oasis |
| Unit 7 | Cosmic Harbor |
| Unit 8 | Tropical Coding Cove |
| Unit 9 | Aurora Peaks |

Открытые территории остаются открытыми. CODE DECAY не должен закрывать миры или отменять пройденные юниты.

## 6. Артефакты

Артефакты мотивируют пользоваться разными режимами, а не повторять только одно удобное упражнение.

| Артефакт | Условие открытия |
|---|---|
| Memory Crystal | выполнить 3 задания Memory |
| Audio Orb | выполнить 3 задания Audio Code |
| Repair Gear | выполнить 3 задания Repair |
| Decoder Lens | выполнить 3 задания Error Hunt |
| Sentence Core | выполнить 3 задания Sentence Build |
| Master Key | воспользоваться 6 разными режимами |
| Prism Fragment | стабилизировать 25 учебных целей |
| Ancient Code | получить Mastered хотя бы для одного юнита |

У артефактов отображаются прогресс, редкость и состояние `FOUND`/`LOCKED`. Артефакты не удаляются при ошибках или отсутствии активности.

## 7. Spirit Stability и CODE DECAY

Stability показывает регулярность занятий, но не изменяет реальные знания ученика.

Правила:

- первые два дня без занятий — без снижения;
- начиная с третьего дня включается **CODE DECAY**;
- затем Stability уменьшается на 10 процентных пунктов за каждый дополнительный день;
- минимальное значение — 20%.

Пример:

```text
2 дня без активности → 100%
3 дня без активности → 90%
4 дня без активности → 80%
5 дней без активности → 70%
```

При сниженной Stability персонаж может выглядеть менее ярко, но интерфейс не должен пугать ученика.

Одна законченная тренировка восстанавливает **+30 Stability**. Если сигнал восстановлен до 100%, ученик получает дополнительно **+20 Energy**.

CODE DECAY никогда не:

- уменьшает mastery слов;
- отнимает уровни и постоянную Energy;
- удаляет Crystal Cores;
- закрывает территории;
- удаляет артефакты;
- меняет настоящую статистику ответов.

### Что может уменьшаться, а что не может

Развитие Code Spirit разделено на **постоянное** и **временное**.

Постоянное развитие не уменьшается автоматически:

- уровень Code Spirit;
- стадия Spark, Sprite, Spirit, Guardian или Master Spirit;
- вся заработанная постоянная Energy;
- открытые аксессуары;
- восстановленные Crystal Cores;
- открытые территории;
- найденные артефакты;
- количество выполненных заданий и правильных ответов;
- история учебных сессий.

Ошибки, подсказки, незавершённая тренировка и потеря серии активных дней не отнимают эти достижения.

Временно уменьшаться может только **Spirit Stability**. Её снижает отсутствие учебной активности начиная с третьего дня. Это влияет на яркость персонажа и состояние сигнала, но не откатывает его настоящий уровень.

Неправильный ответ может перевести конкретное слово в состояние `unstable`. Это не наказание и не удаление прогресса: приложение лишь отмечает, что слово нужно показать ещё раз в другом задании. Уже заработанная Energy при этом сохраняется.

Вернуть Stability можно обычным обучением:

```text
Законченная тренировка → +30 Stability
Полное восстановление до 100% → +20 Energy
```

Полностью удалить постоянное развитие можно только отдельной ручной командой сброса данных с подтверждением. Автоматически приложение этого никогда не делает.

## 8. Active Days

Каждый день, когда ученик выполняет задания, сохраняется как активный. На странице Rewards показывается количество Signal Days за последние семь дней.

Потеря серии не является наказанием и не отнимает постоянные награды.

## 9. Что видит ученик

На странице Rewards ученик видит:

- текущую стадию Code Spirit;
- уровень и шкалу Energy;
- открытые и будущие аксессуары;
- прогресс Crystal Cores;
- восстановленные и закрытые территории;
- коллекцию артефактов;
- Stability и состояние сигнала;
- активные дни.

## 10. Что видит учитель

В Teacher Dashboard отображаются:

- уровень и стадия Code Spirit ученика;
- Energy и Stability;
- процент прохождения курса;
- количество стабильных и освоенных целей;
- сложные слова;
- последние учебные сессии;
- ученики, которым требуется внимание после длительного отсутствия.

Учитель видит награды как дополнительный показатель активности. Учебная статистика и награды остаются разными показателями.

## 11. Где хранятся данные

Сейчас работающая локальная версия сохраняет награды, прогресс и активность в IndexedDB браузера. Поэтому данные сохраняются после обновления страницы на том же устройстве и в том же браузере.

Для работы между разными устройствами и между student/teacher host подготовлена облачная схема Supabase. После подключения Supabase ученический и учительский интерфейсы будут использовать одну базу с разграничением доступа.

## 12. Технические источники правил

- модель наград: `src/domain/rewards.ts`;
- начисление Energy, Stability и сохранение сессий: `src/data/db.ts`;
- экран наград: `src/pages/RewardsPage.tsx`;
- таблицы облачной базы и правила доступа: `supabase/migrations/202608140001_accounts_rewards.sql`;
- централизованные пути к изображениям: `src/config/rewardsAssets.ts`.

Главный принцип системы:

**LEARN → MASTER → RESTORE → EVOLVE → DISCOVER**
